# Uso local no laboratório

Esta versão não depende de backend, conta, banco de dados, telemetria ou serviço externo. Os cálculos e os dados sintéticos ficam no navegador.

## Preparar antes da aula

1. Instale as dependências uma vez com `npm install`.
2. Gere a versão estática com `npm run build`.
3. Sirva a pasta gerada com `npm run preview -- --host 0.0.0.0` ou com o servidor local definido pela escola.
4. Abra a rota indicada no roteiro docente em cada computador ou Chromebook.
5. Desconecte temporariamente a internet e confirme que os módulos continuam disponíveis na rede local.

## Conferência mínima

- um equipamento por estudante, usando Chromebooks para completar o laboratório;
- navegador atualizado, teclado e touchpad funcionando;
- projeção legível do fundo da sala;
- modo aula selecionado;
- cópia da pasta `dist/` preservada em outro equipamento;
- plano alternativo de projeção coletiva com produção individual em papel.

O diagnóstico inicial e o instrumento final não são distribuídos pelo site. Eles permanecem no protocolo restrito da pesquisa.
