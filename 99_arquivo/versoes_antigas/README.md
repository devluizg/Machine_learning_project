# Arquivo de versões antigas

Esta pasta preserva materiais substituídos para consulta histórica. Os arquivos aqui guardados não são a referência de trabalho atual.

- `qualificacao/`: versões anteriores ao projeto de qualificação versão 5.
- `metodologia/`: instrumentos metodológicos superados por versões atuais.
- `concepcao/`: registros iniciais de concepção, anteriores à proposta metodológica atual.
- `prototipos/`: estudos exploratórios de protótipos substituídos pelo site atual.
- `artefatos_temporarios/`: extrações e artefatos de trabalho que não devem orientar a pesquisa.

A versão principal da qualificação está em `01_qualificacao/texto/projeto_qualificacao_v5_20261018/`.
